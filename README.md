# Questlog

A mobile-first RPG habit tracker. Complete daily quests, earn XP, level up, and build your streak.

## Current build
- Responsive mobile/desktop UI
- RPG-style character progression
- Daily habit quests with XP rewards
- Leveling and streak tracking
- Local device persistence via `localStorage`
- No backend required for the current prototype

## Run
Open `index.html` in a browser, or deploy the repository as a static site.
